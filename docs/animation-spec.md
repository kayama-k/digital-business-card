# アニメーション仕様

更新日：2026-09-20  
ステータス：画面遷移と波形の基本方針を確定済み

## 対象

- プロフィールとポートフォリオの横方向の画面遷移
- 画面遷移時の上下の青い波形
- 保存・シェアのボトムシート
- ボタン押下時の小さな反応

## 画面遷移

| 操作 | 画面の動き |
| --- | --- |
| プロフィール → ポートフォリオ | 現在画面が左へ抜け、新画面が右から入る。 |
| ポートフォリオ → プロフィール | 現在画面が右へ抜け、新画面が左から入る。 |
| 「反転」メニュー | 名刺全体を平面上で180度回転する。鏡映・3Dの裏返しは行わない。プロフィール／ポートフォリオを選ぶと表向きへ戻る。 |

横移動と波形は、操作と同時に開始する。

## 波形

- 発生条件はプロフィール／ポートフォリオの切替時のみ。保存・シェアの表示時には動かさない。
- 一度だけ動き、常時ループしない。
- 引き波のような液体らしい揺らぎを残しつつ、激しくしない。
- 基準形状はアニメーションの開始・終了で完全に同一にする。終了時に静止形状へ差し替える際の段差を生ませない。
- デフォルトの全体時間は `1.3秒`。画面の横移動は先に終わり、波だけが終端まで穏やかな余韻を残して収束する。
- デフォルト振幅は中。SVG viewBox上の基準値は `19` とする。
- 減衰は長い。波は全体時間の終端まで残して収束する。
- イージングは「ゆっくり始まり、ゆっくり終わる」をデフォルトとする。
- `prefers-reduced-motion` を尊重する。
- 「反転」メニューのカード回転は `720ms`、ゆっくり始まり終わるイージングを使う。`prefers-reduced-motion` が有効な場合は向きだけを即時に切り替える。
- 下部メニューの選択背景は、`320ms` のフェードと `420ms` の小さな拡縮で柔らかく切り替える。押下時のボタン縮小も `260ms` で戻す。
- 保存・シェアのボトムシートは下端から `380ms` で表示し、閉じる際は背景を暗転解除しながら `300ms` で下へ退場する。上部のつまみを下へスワイプして閉じられ、ドラッグ中はシートが指に追従する。
- ボトムシートも `prefers-reduced-motion` を尊重する。

## 実装時の可変設定

時間・振幅・減衰・イージング・開始タイミングを個別の設定値として管理し、後から再調整可能にする。
