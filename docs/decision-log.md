# 意思決定ログ

更新日：2026-09-20

## 確定事項

| 分類 | 決定内容 |
| --- | --- |
| リポジトリ名 | `digital-business-card` |
| GitHubの可視性 | 公開（Public） |
| 初期技術構成 | React、TypeScript、Vite、CSS、GitHub Pages。バックエンド、データベース、管理画面は初期版に含めない。 |
| 公開画面 | ログイン不要の縦型デジタル名刺。スマートフォン表示を優先する。 |
| 保存・シェア | 別画面ではなく、ボトムシートとして表示する。 |
| アニメーションの対象 | 波はプロフィール／ポートフォリオの画面切替時だけ動かす。保存・シェアでは波を動かさない。 |
| 遷移開始 | 画面の横移動と波形を同時に開始する。 |
| 波の時間 | デフォルトは1.3秒。 |
| 波の振幅 | デフォルトは中。SVG viewBox上の基準値は19とし、実装では可変設定として管理する。 |
| 波の減衰 | デフォルトは長い。全体1.3秒の終端まで、穏やかな余韻を残して収束させる。 |
| 波のイージング | デフォルトは「ゆっくり始まり、ゆっくり終わる」。 |
| 波の収束 | 開始・終了の基準形状を同一にし、静止状態への切替で段差を生ませない。長い余韻で穏やかに収束させる。 |
| 保存ファイル | 印刷用途は想定しない。PNGは`1024 × 1536px`、PDFは同じ保存用デザインを1ページの`2:3`比率で出力する。 |
| QRコード | 名刺アプリへの入口QRとポートフォリオQRの両方を、各URLの設定値から生成する。 |
| 公開URL | 初期版はGitHub Pagesの標準URLを使う。独自ドメインは取得後に設定する。 |
| タイトルフォント | Katakanaboy / RはWebフォント化せず、タイトルのみSVGアウトラインで使用する。代替テキストを付ける。 |
| 紙テクスチャ | Figmaで使用中の画像を正式素材として書き出して使用する。 |
| プロフィール画像 | Figmaのプロフィールイラストを正式素材として書き出して使用する。 |
| 更新しやすさ | 文章、URL、アニメーション値は一つの設定データへ集約し、画像素材は差し替え可能なアセットとして分離する。 |

## 要件確認の状態

実装開始前に決める事項は完了。実装時も上記の設定値は再調整可能な構造として扱う。
