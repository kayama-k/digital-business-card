# 最小コードレビュー

通常の変更は `npm run verify` を通過すればよい。人またはサブエージェントによる追加レビューは、公開事故の影響が大きい変更にだけ使う。

## 追加レビューが必要な変更

- GitHub Actions、GitHub Pages、公開URL、公開範囲の変更
- 秘密情報、環境変数、外部サービス連携に関わる変更
- 複数コンポーネントまたは設定構造をまたぐリファクタリング
- `npm run verify` が失敗した、または結果を説明できない変更

## 確認項目

1. 変更は依頼された範囲に収まり、公開してよい情報だけを含むか。
2. `src/config/card.ts` を唯一の表示設定源として維持しているか。
3. `npm run verify` が成功しているか。変更した利用者向け挙動に対応するE2Eがあるか。
4. アクセシビリティや共有・保存の代替経路を壊していないか。

レビュー結果は、問題なしまたは具体的な修正事項だけを短く記録する。追加レビューは日常的な文言・素材・レイアウト変更の前提条件にはしない。
